# JsPlumb Angular Orgchart

### Setup

This project uses Angular 17 and JsPlumb Toolkit 6.90.0+.

Licensees and evaluators can use our [private NPM repository](https://docs.jsplumbtoolkit.com/toolkit/6.x/lib/installation#npm-setup) to access JsPlumb. You can also change the `@jsplumbtoolkit` dependencies inside package.json to use `file:....` URLs if you wish to use local copies of the JsPlumb packages.

```bash
npm i
```

### Running the app

```bash
ng serve
```
